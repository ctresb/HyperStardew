# HyperStardew

Mod de hipertraducão pro Stardew Valley feito por C3B.

## O que é

Adiciona um idioma novo no Stardew Valley chamado **HyperStardew**. Todos os textos do jogo foram passados por 25 idiomas aleatorios via Google Tradutor antes de voltar pro português. O resultado é caótico, engraçado e, geralmente, não faz sentido.

Inclui:
- 19.000+ falas e textos hipertraduzidos;
- Imagens do jogo (placas, menus, botões) também editados manualmente;
- Botão próprio no menu de idiomas com o LOGO DO JOGO hypertraduzido;

## Como instalar

### Passo 1: Instalar o SMAPI

1. Entra na pasta 1-SMAPI-installer
2. Roda o arquivo install on Windows.bat (clique duplo)
3. Escolhe a opcão 1 (Install) quando perguntar
4. Espera terminar e fecha o terminal

### Passo 2: Instalar o Content Patcher

1. Abre a pasta 2-ContentPatcher
2. Copia a pasta ContentPatcher de dentro dela
3. Cola em C:\Program Files (x86)\Steam\steamapps\common\Stardew Valley\Mods\
* - Se não tiver a pasta Mods, crie ela.

### Passo 3: Instalar o HyperStardew

1. Abre a pasta 3-HyperStardew
2. Copia ela inteira pra mesma pasta Mods do Stardew Valley

A estrutura final deve ficar:

    Stardew Valley\
      Mods\
        ContentPatcher\
        HyperStardew\

### Passo 4: Rodar o jogo

1. Abre o Steam
2. Clica em Jogar no Stardew Valley
3. Vai aparecer opcão pra Jogar com SMAPI - clica nela
4. O jogo abre junto com uma janela preta de console (não fecha ela!)

### Passo 5: Trocar pro idioma Hyper

1. No menu principal, clica no Botão de idiomas
2. Vai na página 2
3. Escolhe HyperStardew como idioma

## Pronto.

Agora, divirta-se...

## Problemas

Se der erro:
- Confere se Mods/HyperStardew/manifest.json existe
- Confere se Content Patcher tambem foi instalado
- Olha a janela preta de console - ela mostra erros
